霓虹潮汐 · Neon Tide
互动式赛博朋克雨夜动画

打开方式
1. 双击 index.html。
2. 推荐使用最新版 Chrome 或 Edge。
3. 页面无需联网，所有程序、动画和音效都在这一个文件里。

操作
- 点击任意一条全息鱼：鱼会游向桥上的人，并显示一段记忆文字。
- P：暂停或继续动画。
- F：进入或退出全屏。
- 点击页面后才会启用环境雨声音频，这是浏览器的声音播放限制。

兼容说明
- 使用原生 WebGL 渲染三维鱼体，不需要安装 Three.js 或其他依赖。
- 如果设备不支持 WebGL，会自动使用 Canvas 2D 版本显示。
- 支持桌面和手机浏览器；手机建议横屏或全屏观看。

分享方式
一、把文件直接发给别人（对方在电脑上双击打开）
1. 可以直接发送 index.html。
2. 也可以发送包含本说明的 ZIP 压缩包，解压后双击 index.html。

二、想要一个网址链接（适合发微信、短信，手机也能直接打开）
1. 用电脑浏览器打开 https://app.netlify.com/drop
2. 把整个 neon-tide-portable 文件夹拖进网页中间的虚线框。
3. 等待上传完成，页面会生成一个类似
   https://随机名字.netlify.app
   的公开网址，把这个链接发给别人即可。

注意：Netlify Drop 生成的链接不需要注册账号；如果想长期保留，可以注册账号认领这个网站。
